# 英语教学工作台 · 一期原型

这是一个可以直接双击打开的网页原型，不需要安装、不需要联网、不需要构建。
推荐用 Edge 或 Chrome 打开。

## 怎么打开

双击 `index.html` 即可。

注意：**整个 `prototype` 文件夹要一起保留**，不要只把 `index.html` 单独拷走，
页面样式和脚本都在 `assets` 文件夹里。

## 里面已经放了示例数据

- 2 个班：高一(3)班、高一(7)班，各 10 名学生
- 3 个词表：必修一 Unit 4（20 词）、Unit 3（12 词）、短语草稿（8 词）
- 3 次听写：2 次已发布、1 次草稿
- 一周 10 节课的课表，以及 7 天的备课状态
- 1 场考试和 10 条成绩（留给第三期）

## 五分钟试一遍

1. **今日**：点第一条课程 → 改备课状态 → 保存。左上角的"备课没就绪"提醒会变少。
2. **词库**：点开任意词表 → "添加词条" → 在"粘贴"里贴 5 个单词 → 导入。
3. **听写**：新建听写 → 三步发布 → 点"录入结果"。
   - 电脑上是"学生 × 单词"的大表格，点格子循环切换。
   - 手机上自动变成"一次一个学生"，右边一个大按钮点着录。
4. **错词**：看班级高频错词 → 勾选几个 → 生成再听写词表。
5. **课表备课**：点任意一格 → 写这节课的备课要点。
6. **设置**：设一个密码 → 刷新页面 → 会出现锁屏。

## 数据存在哪里

数据存在浏览器的本地存储里（localStorage），不会上传到任何服务器。

- 换电脑、换浏览器、清理浏览器数据，数据都会没有。
- 请定期在 **设置 → 备份与恢复 → 导出** 存一份 JSON 到网盘或 U 盘。
- 恢复时选同一个文件即可。恢复前系统会自动留一份快照，24 小时内可以回滚。
